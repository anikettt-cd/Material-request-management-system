Viraj MDM Portal (Material Request Management System)

A full-stack enterprise web application designed to streamline and automate material request workflows, approvals, and master data management across various organizational departments.

Key Features

Role-Based Access Control (RBAC): Supports distinct workflows and permissions for Creators, Plant Heads, Material Heads, Purchase, GST, Store, and IT Admin roles.

Automated Material Lifecycle: Tracks requests seamlessly from initial creation through multi-stage reviews down to final material code generation.

Secure Authentication: Implements token-based security using HTTP-only cookies and Bcrypt password hashing for enterprise-grade protection.

Robust Backend & Database: Powered by a high-performance FastAPI Python backend integrated with a structured MySQL relational database.

Modern Frontend Interface: Built with React and Vite to deliver a responsive, clean, and intuitive user dashboard experience.

Tech Stack

Backend: Python, FastAPI, SQLAlchemy, PyMySQL, Bcrypt, PyJWT, Passlib

Frontend: React, Vite, JavaScript, Axios, CSS

Database: MySQL Server / MySQL Workbench
